# Student Expense Tracker

A simple C++ console-based application designed to help students record and manage their daily expenses.

## Features

- Add new expenses
- View all recorded expenses
- Search expenses by category
- Calculate total expenses
- Delete expenses
- Save expenses using file handling
- Load previously saved expenses when the program starts

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL Vector
- File Handling
- Git & GitHub

## C++ Concepts Used

- Classes and Objects
- Functions
- Vectors
- Loops
- Conditional Statements
- File Input/Output
- Input Validation
